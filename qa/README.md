## 기존 구매·로그인·업로드 회귀 테스트

2026-10-24에 현재 서비스 코드에 적용한 QA 실행 묶음입니다. 과거 수동 테스트 횟수나 운영 성과를 소급한 기록이 아닙니다.

## 범위

- 구매 4건: 품절, 재고 상한, 교재 ID, 주문서 수량·금액
- 인증 3건: 조회 무응답, 미인증, 인증 완료
- 업로드 3건: 15MB 경계의 바로 아래·일치·바로 위
- [TC 원본](cases.json)의 ID를 실행 결과와 결함 보고에 그대로 사용합니다.
- 실제 React 화면과 업로드 함수를 실행합니다. 인증·교재·장바구니 API 응답 및 이미지 변환·저장소는 테스트 데이터로 대체합니다. PG 승인, 운영 DB, 실제 저장소 전송, 실제 소셜 로그인 검증은 범위 밖입니다.

## 실행

저장소 루트의 의존성을 설치한 뒤 실행합니다. Node 22 이상.

```sh
npm ci
npm --prefix qa ci
npx --prefix qa playwright install chromium
npm --prefix qa test
```

설치된 Chrome 사용 시 `PLAYWRIGHT_CHANNEL=chrome` 환경 변수를 지정합니다. 서버는 127.0.0.1:5197에서 자동 시작·종료합니다. 비밀키 없이 합성 회원과 응답으로 실행하며 외부 브라우저 요청을 차단합니다.

## 산출물

`qa/results/`에 `results.json`, `report.html`, 화면과 실패 시 trace가 생성됩니다. JSON에는 UTC 실행 시각, 코드 커밋, 실행 환경, TC별 기대·실제·상태가 포함됩니다. GitHub Actions는 같은 명령으로 실행하고 산출물을 보관합니다.

- [BR-IMG-001: 초과 용량 반올림 표기](bugs/BR-IMG-001.md)
- [BR-PAY-001: 기존 결제 중단 이력 정리](bugs/BR-PAY-001.md)

통과는 정의된 범위의 통과입니다. 전체 서비스 품질, 운영 API, 실기기 호환성을 보증하지 않습니다. 별도 표기 개선 관찰은 기능 TC 합격 수에 포함하지 않습니다.

## 설계 근거

- Playwright 공식 Network/CI 문서: 응답 대체, 브라우저 검증, 실행 결과 보관
