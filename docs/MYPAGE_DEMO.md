# 운영진 마이페이지 체험

2026-10-06: 사용자 요청으로 실제 계정 생성 대신 로그인 없는 데모 링크를 사용한다.

- 구매 내역: https://subook.kr/mypage?demo=1#purchases
- 수거·판매 내역: https://subook.kr/mypage?demo=1#sales
- 정산 내역: https://subook.kr/mypage?demo=1#settlements

실제 마이페이지 구성요소에 주문 9건, 수거 8건, 정산 예정·완료, 보유·사용·만료 쿠폰을 표시한다. 주문은 입금대기, 결제 완료(배송준비), 배송중, 배송완료, 구매확정, 취소, 전액·부분환불, 반품 접수 사례를 포함한다. 표지·연락처·주소·계좌·운송장도 예시다.

구매확정, 주문·수거 취소, 환불 신청, 프로필·배송지·정산계좌 변경은 별도 데모 localStorage에서만 처리한다. 후기·후기 포인트 체험은 화면을 새로고침하면 초기화된다. 쿠폰 발급·배송 조회·새 수거 접수는 안내만 표시한다. 상단 **샘플 초기화**는 데모 저장값만 지운다.

로그인한 상태에서도 데모 식별자를 우선 사용하며 실계정 DB·Auth·쿠폰·찜 목록과 분리한다. 데모 화면에서 발생한 앱의 GA/Meta 이벤트 호출은 억제한다. 사이트 공통 자동 페이지뷰까지 차단한다는 의미는 아니다. 헤더·푸터로 데모 밖의 일반 서비스에 이동하면 일반 서비스 동작으로 돌아온다.

검증: 실제 Supabase client 접근을 실패시키는 서비스 테스트로 프로필·주소·계좌·주문·수거 변경과 실계정 캐시 보존을 확인한다. 날짜·금액 일치, 월초 정산, 빈 컬렉션 유지, URL별 계측 분리도 검사한다.
