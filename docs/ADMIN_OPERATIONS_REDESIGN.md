# 어드민 운영 화면 개편 — 2026-10-06

운영 업무를 8개 메뉴군으로 정리하고, 조회 조건을 유지하면서 실제 처리 대상으로 이동하도록 개편했다. 기존 수거·상품 등록·환불·정산 정책과 URL은 유지한다.

## 메뉴와 새 기능

| 위치 | 반영 내용 |
| --- | --- |
| 오늘 할 일 | 업무 단위별 대기 건수, 미처리 환불·지연 출고/수거/검수·계좌 미등록·알림 실패·문의 기한 목록과 대상 링크 |
| 작업·변경 이력 | 사진 변환·CJ 송장·CSV 송장·엑셀 작업의 대상/진행/실패 결과, 기존 상품/교재 이력과 신규 주문/수거/콘텐츠 변경 항목 검색 |
| 입고·검수 | 수거/검수 URL 조건, 개인 저장 보기, 상세에서 원래 검수 목록 복귀, 요청/검수 상세 타임라인 |
| 상품·재고 | 390px 모바일 카드, 상세 주소, 개인 저장 보기, 오래된 재고·현재 판매가 합계·최근 30일 판매와 재고 소진 예상 |
| 주문·배송 | 출고 대기/환불 신청/회수 진행/재고 보류 보기, 위치·일련번호순 피킹 및 포장 체크, 모바일 카드, 상세 타임라인 |
| 정산 | 기존 셀러·계좌 묶음 유지, 지급 완료 원장에 연결된 환불 신청/처리 확인 목록 |
| 고객·CS | 문의별 담당자·우선순위·처리 기한·상태·메모, 비회원 연락처와 주문/수거 ID 연결, 회원 교차 링크의 ID 기준 조회 |
| 홈 편집 | 기존 테마/추천/배너 편집 탭, PC·모바일 구성 미리보기, KST 시각별 배너·팝업과 연결 상품 상태 확인 |
| 쿠폰·행사 | KST 날짜 왕복, 만료/예정/발급 소진 표시, 캠페인/CS/테스트 분류, 행사 선택 및 조회 명단 CSV |
| 성과 | 매출·유입·광고와 운영 분석 탭 연결, 운영 분석의 중복 매출 표시 정리 및 집계 기준 표시 |

사이드바에서 메뉴 검색·즐겨찾기·그룹 접기가 가능하다. 즐겨찾기와 저장한 보기는 현재 계정의 브라우저에 저장한다. 홈 미리보기는 저장된 구성과 판매 가능 상품 최대 8종을 보여주며 실제 고객 홈을 실행하거나 방문 지표를 발생시키지 않는다.

## 검증

- 전체 프런트 lint, admin 테스트 149개, public 테스트 295개, 두 웹앱 build 통과.
- 신규 DB 회귀 테스트 8개: 비관리자 접근 차단, 페이지 이전 필터, KST 경계, CS 동시 수정, 쿠폰 분류, 피킹/포장 제약, 작업 기록 권한, 정산 금액 불변.
- 기존 결제·환불·수거 관련 테스트 53개 통과.
- 로그인한 실제 데이터로 데스크톱 1440px와 모바일 390px 조회 확인. 환불 필터 새로고침 유지, 회원 ID 링크, 검수 상세 복귀, 쿠폰/문의 모달 Escape, 모바일 상품 수정 접근과 닫은 뒤 위치 보존 확인.
- 운영 환불·정산 지급·송장 발급·알림 발송은 검증용으로 실행하지 않았다. 피킹/포장 쓰기는 격리 DB 테스트로 검증했다.

## 기록 범위와 복구

신규 변경 이력은 배포 이후 기록된다. 이전 상품/교재 이력은 합쳐 조회하지만, 과거 주문/콘텐츠 변경 내용을 복원하지 않는다. 개인정보 값은 이력에 복제하지 않고 변경 필드명만 기록한다.

대량 작업 이력 저장 실패가 실제 작업 실패를 뜻하지는 않는다. 중단·오래된 진행 중 작업은 주문별 송장이나 상품 결과를 확인한 뒤 기존 화면에서 후속 처리한다. 자동 재실행 기능은 제공하지 않는다.

행사 CSV는 현재 조회한 명단 범위이며, 서버 제한으로 전체보다 적으면 그 수를 표시한다. 재고 분석은 현재 가용 재고와 최근 판매 기준이며 과거 반복 품절 횟수는 집계하지 않는다.

DB 변경은 신규 운영 테이블·관리자 전용 RPC·기록 트리거 추가다. 기존 주문/수거 목록 RPC와 금융 처리 RPC는 보존했다. 문제 시 이전 어드민 버전으로 복귀할 수 있으며 신규 기록 테이블은 보존한다. 스키마 삭제를 복구 절차로 사용하지 않는다.
