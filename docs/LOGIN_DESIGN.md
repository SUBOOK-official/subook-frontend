# 로그인 화면 디자인

2026-10-01 사용자가 기존 로그인 화면의 디자인 개편을 요청했다.

## 참고 화면

실제 브라우저에서 확인한 레퍼런스:

- [Headspace](https://my.headspace.com/login): 브랜드 이미지와 입력 영역의 구분, 명확한 로그인 동작.
- [Milanote](https://app.milanote.com/login): 소셜 로그인과 이메일 로그인 구분, 입력란 주변의 보조 링크 배치.
- [Mailchimp](https://login.mailchimp.com), [Readwise](https://readwise.io/accounts/login/): 로그인 폼과 주변 정보의 밀도 비교.

## 수북 적용

- PC에서는 기존 책 이미지와 큰 제목을 왼쪽에, 로그인 폼을 오른쪽에 배치한다.
- 모바일에서는 사진을 짧은 상단 배너로 바꾸고 입력 영역을 한 열로 제공한다.
- 수북 로고, 남색/연하늘색 디자인 토큰, LINE Seed KR, 기존 아이콘을 사용한다.
- 카카오·구글 로그인 뒤 이메일 로그인 순서를 유지한다. 비밀번호 찾기는 비밀번호 라벨 옆, 회원가입과 비회원 주문 조회는 폼 아래에 둔다.
- 인증 처리·로그인 후 목적지·로그인 상태 유지·소셜 전용 계정 안내를 유지한다.
- 로그인 화면에서 제거된 ‘이메일을 등록하지 않은 기존 계정 찾기’는 다시 노출하지 않는다.

## 검증

- `npm run lint`, `npm run test:public`(273개), `npm run build:public` 통과.
- `scripts/verify-login-design.mjs`: 1440/768/390/320px 화면과 가로 넘침, 필수 입력·이메일 형식·비밀번호 표시·Enter 이동, 잘못된 비밀번호·소셜 전용 안내, 카카오/구글 시작 URL, 이메일 로그인 성공 후 경로/세션 유지 확인.
- 브라우저 검증은 모든 인증·DB·외부 요청을 모의 응답으로 처리한다. 실제 OAuth 제공자의 인증 완료나 실계정 변경을 수행하지 않는다.
- 실행 시 Playwright와 Chrome이 필요하다. `QA_ORIGIN`으로 확인 대상 주소를 지정하며 기본 주소는 `http://127.0.0.1:4173`이다.
