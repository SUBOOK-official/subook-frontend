# UI 1차 수정

브랜치: `feat/ui-first-update`

- 주문 상품 아래에 과목·유형 기반 유사 교재를 표시합니다. 처음 3권과 더보기, 옵션 선택 및 + 버튼으로 추가할 수 있습니다. 담기는 최신 공개 여부·판매 상태·가격을 재조회하고 주문 목록에 반영합니다. 추가 구매는 선택 사항이며 변경된 최종 금액을 확인한 뒤 결제합니다.
- 홈 기본 정렬은 추천순입니다. 관리자 지정 교재가 먼저 나오며 나머지는 기존 인기순입니다. 검색 기본 정렬은 관련도순을 유지합니다.
- `/admin/recommendations`에서 상품 검색, 추천 등록, 순서·문구·노출 여부를 저장합니다. 기본 등록 상태는 비노출입니다.
- 홈 배너는 공개·판매 가능한 추천 상품의 표지와 소개 문구를 자동 조합합니다. AI 이미지 생성 API는 연결하지 않았습니다.
- 회원 추천은 최근 구매(취소·환불 제외), 찜한 교재, 베스트 순입니다. 추천 상품은 구매한 상품과 품절 상품을 제외합니다. 개인정보는 브라우저 영구 캐시에 저장하지 않습니다.
- 상세 배송비에 50,000원 이상 무료배송을 표시합니다. 운영 배송비 상수를 참조합니다.

## 운영 적용

`docs/sql/20260928_product_recommendations.sql`을 public-web/admin-web이 함께 쓰는 Supabase 프로젝트에 적용해야 추천 관리 저장 및 배너가 동작합니다. 이 작업에서는 운영 DB에 적용하지 않았습니다. 적용 전에는 홈이 기존 인기순으로 동작하고 배너는 숨겨집니다. 관리자 화면은 연결 오류를 명시합니다.

추천순은 전체 필터 결과를 500건 단위로 조회한 뒤 순서를 적용해 페이지 경계 중복을 방지합니다. 현재 방식은 대규모 카탈로그에서 조회 비용이 늘어나므로, 향후 서버 RPC 내 추천 순위 조인으로 전환하는 것이 좋습니다.

실제 로그인 구매·찜 데이터 및 결제 승인, DB 권한별 저장은 운영 연결 환경에서 별도 검증이 필요합니다.

## 테마 바로가기

과목별 바로가기는 홈에서 제거했습니다. `/admin/themes`에서 정사각형 아이콘, 20자 이내 테마명, 교재 목록(개수 상한 없음)을 등록합니다. 검색 결과 전체 선택과 선택 교재 일괄 추가, 교재 순서, 홈 노출 순서, 노출 여부를 설정할 수 있습니다. 기존 테이블의 100권 제한은 `docs/sql/20260928_remove_theme_product_limit.sql`로 해제합니다. 저장된 테마는 `/themes/:id`로 연결되며 공개·구매 가능한 교재만 표시합니다.

테마 저장에는 `docs/sql/20260928_home_theme_promotions.sql` 적용이 필요합니다. 운영 DB에는 아직 적용하지 않았으며, 등록된 테마가 없거나 조회가 실패하면 홈 테마 영역은 숨겨집니다.
