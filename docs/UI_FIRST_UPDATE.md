# UI 1차 수정

원본 PR #22와 운영 배포 보완사항.

- 주문 상품 아래에 과목·유형 기반 유사 교재를 표시합니다. 처음 3권과 더보기, 옵션 선택 및 + 버튼으로 추가할 수 있습니다. 담기는 최신 공개 여부·판매 상태·가격을 재조회하고 주문 목록에 반영합니다. 추가 구매는 선택 사항이며 변경된 최종 금액을 확인한 뒤 결제합니다.
- 홈 기본 정렬은 추천순입니다. 관리자 지정 교재가 먼저 나오며 나머지는 기존 인기순입니다. 검색 기본 정렬은 관련도순을 유지합니다.
- `/admin/recommendations`에서 상품 검색, 추천 등록, 순서·문구·노출 여부를 저장합니다. 기본 등록 상태는 비노출입니다.
- 홈 배너는 공개·판매 가능한 추천 상품의 표지와 소개 문구를 자동 조합합니다. AI 이미지 생성 API는 연결하지 않았습니다.
- 회원 추천은 최근 구매(취소·환불 제외), 찜한 교재, 베스트 순입니다. 추천 상품은 구매한 상품과 품절 상품을 제외합니다. 개인정보는 브라우저 영구 캐시에 저장하지 않습니다.
- 상세 배송비에 50,000원 이상 무료배송을 표시합니다. 운영 배송비 상수를 참조합니다.

## 운영 적용

정식 소스는 backend 저장소의 `supabase/migrations/20260927192942_curated_recommendations_and_themes.sql`입니다. 과거 `docs/sql` 초안은 삭제했습니다. backend migration을 먼저 적용하고 public/admin을 배포합니다.

추천순은 서버에서 추천 우선순위 → 기존 인기순으로 정렬합니다. 검색·강사·연도·시리즈 필터와 기존 노출 정책을 보존하며 전체 카탈로그를 브라우저에 내려받지 않습니다. 배너는 구매 가능한 상품을 먼저 걸러 최대 8개 채웁니다.

테이블은 RLS로 활성 콘텐츠만 공개 조회하고 수정은 관리자만 허용합니다. 관리자 저장은 `updated_at`으로 동시 수정 충돌을 감지하며 실패한 쓰기를 자동 재시도하지 않습니다. 주문 추천은 회차·등급·가격으로 옵션을 묶고, 추가한 항목을 삭제할 수 있습니다. 현재 주문의 history 상태를 갱신해 새로고침 시 복원하며 늦은 가격 검증이 추가·삭제한 항목을 덮어쓰지 않습니다. 실제 결제 승인 흐름은 변경하지 않습니다.

## 테마 바로가기

과목별 바로가기는 홈에서 제거했습니다. `/admin/themes`에서 정사각형 아이콘, 20자 이내 테마명, 교재 목록(100권 제한 없음)을 등록합니다. 검색 결과 전체 선택과 선택 교재 일괄 추가, 교재 순서, 홈 노출 순서, 노출 여부를 설정할 수 있습니다. `/themes/:id`에서 공개·구매 가능한 교재만 24개씩 조회합니다. 품절·삭제·숨김 상품과 중복 ID를 제외한 개수로 페이지를 계산합니다.

콘텐츠는 운영자가 등록합니다. 등록 전에는 배너·테마 바로가기가 표시되지 않고 추천순은 기존 인기순과 같습니다. 이상 발생 시 public/admin을 직전 배포로 되돌려도 기존 목록 RPC와 호환됩니다. DB 테이블과 콘텐츠를 삭제하지 말고 필요하면 관리자 화면에서 노출을 해제합니다.

검증: public lint/test/build, admin build, shared client/domain 단위 테스트, backend `node scripts/test-curated-content.mjs` (격리 DB 권한·정렬·필터·100개 초과 페이지·동시 저장 검증). 브라우저 주문 검증은 테스트 응답으로 진행하며 실제 결제를 발생시키지 않습니다.
